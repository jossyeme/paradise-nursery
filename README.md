# Paradise Nursery

Paradise Nursery is a React and Redux houseplant shopping application, built as the final project for the IBM course Developing Front-End Apps with React.

## Features

- Landing page with a background image, the company name, a paragraph about the company, and a Get Started button that leads to the plants page.
- Product listing page with houseplants grouped into categories. Each plant shows a thumbnail, name, and price, plus an Add to Cart button that disables once the plant is added.
- Shopping cart page showing each plant's thumbnail, name, unit price, and total cost, with buttons to increase, decrease, or delete items. It also shows the total number of plants, the total cost, a Checkout button that displays "Coming Soon", and a Continue Shopping button that links back to the plants page.
- Navigation bar on the plants and cart pages with links to Home, Plants, and Cart, and a cart icon that shows the total number of items.

## Tech Stack

- React
- Redux Toolkit
- React Router
